# Self-Correcting Multi-Agent AI System

A self-correcting multi-agent AI application built with **LangGraph, Google Gemini, LangChain, FastAPI, and JavaScript**.

The system uses a **Writer → Reviewer → Reviser** agent workflow to generate an answer, evaluate it against predefined quality criteria, and iteratively improve it when necessary.

Instead of returning the first response generated by an LLM, the system introduces a verification loop that allows the generated answer to be reviewed and revised before the final response is presented to the user.

---

## 🚀 Overview

Large Language Models can generate useful answers, but their first response may not always satisfy the required quality criteria.

This project demonstrates an **agentic self-correction workflow** where multiple specialized agents collaborate:

```text
                         User Topic
                             │
                             ▼
                    ┌─────────────────┐
                    │  Writer Agent   │
                    │    Generate     │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Reviewer Agent  │
                    │    Evaluate     │
                    └────────┬────────┘
                             │
                       ┌─────┴─────┐
                       │           │
                    PASS         REVISE
                       │           │
                       ▼           ▼
                     END    ┌───────────────┐
                            │ Reviser Agent │
                            │    Improve    │
                            └───────┬───────┘
                                    │
                                    └──────────────► Reviewer
```

The loop continues until the reviewer approves the answer or the maximum revision limit is reached.

## 🧠 Agent Architecture

### 1. Writer Agent

The Writer Agent generates the initial response to the user's topic.

Its instructions are designed to produce:

* Beginner-friendly explanations
* Simple language
* An everyday analogy
* A small concrete example
* A concise response

The Writer Agent uses the configured Gemini model to generate the draft.

---

### 2. Reviewer Agent

The Reviewer Agent acts as a verifier in the loop.

It evaluates the generated response against four criteria:

1. Is the explanation easy for a beginner?
2. Does it contain an everyday analogy?
3. Does it contain a small concrete example?
4. Does it remain focused on the requested topic?

The reviewer produces a structured decision:

```json
{
  "decision": "PASS",
  "feedback": ""
}
```

or:

```json
{
  "decision": "REVISE",
  "feedback": "Add a clearer everyday analogy."
}
```

The reviewer uses a Pydantic `Review` schema with a restricted `PASS` / `REVISE` decision. This provides structured output rather than relying only on free-form LLM text.

---

### 3. Reviser Agent

When the reviewer returns `REVISE`, the Reviser Agent receives:

* The original topic
* The current answer
* The reviewer's feedback

It then generates an improved answer.

The revised answer is sent back to the Reviewer Agent for another evaluation.

This creates the self-correction loop:

```text
Writer
   ↓
Reviewer
   ↓
REVISE
   ↓
Reviser
   ↓
Reviewer
   ↓
PASS
   ↓
Final Answer
```

## 🔀 Workflow Orchestration

The workflow is implemented using **LangGraph's StateGraph**.

The shared workflow state contains:

```python
class State(TypedDict):
    topic: str
    draft: str
    feedback: str
    decision: str
    revision_count: int
```

This state allows the agents to share information throughout the workflow.

The graph contains:

```text
START
  ↓
Writer
  ↓
Reviewer
  ↓
Conditional Router
  ├── PASS ──────► END
  │
  └── REVISE ───► Reviser
                       │
                       ▼
                    Reviewer
```

The workflow also has a maximum revision threshold to prevent the system from entering an infinite correction loop.

## 🔌 API

### `GET /`

Returns the web application interface.

### `GET /api/config`

Returns runtime configuration information.

### `POST /api/run`

Runs the complete self-correcting agent workflow.

Example request:

```json
{
  "topic": "What is an AI agent?"
}
```

Example response structure:

```json
{
  "topic": "What is an AI agent?",
  "events": [],
  "final_answer": "An AI agent is...",
  "revision_count": 1
}
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Omenka-da-boss/self-correct-agent.git
```

```bash
cd self-correct-agent
```

### 2. Create a virtual environment

Windows:

```bash
python -m venv .venv
```

Activate it:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file:

```env
GOOGLE_API_KEY=your_google_api_key
```

Do not commit your `.env` file to GitHub.

### 5. Start the application

```bash
python app.py
```

The application runs on:

```text
http://localhost:8000
```
